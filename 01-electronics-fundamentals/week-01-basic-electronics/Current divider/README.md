# Topic: Current Divider

---

## What I Learned

The current is divided between every branch in a **parallel circuit**.

The voltage is the same across every branch in a **parallel circuit**.

In a **series circuit**, the current is the same through every component, while the voltage is divided between the resistors.

To find the total current in a parallel circuit, we add the current of every branch:


I_T = I_1 + I_2 + I_3


---

## Important Concepts

### Voltage

In a parallel circuit, the voltage is the same across every branch.

### Current

In a parallel circuit, the current is divided between the branches.

The branch with the **smaller resistance receives more current**.

---

## Formulas

### Ohm's Law

I = {V}/{R}


### Total Current

I_T = I_1 + I_2 + I_3


### Current Divider

For two resistors:


I_1 = I_T({R_2}/{R_1 + R_2})


I_2 = I_T({R_1}/{R_1 + R_2})


### Total Current Using Equivalent Resistance


I_T = {V}/{R_T}


---

## Key Rule

**Series → same current, divided voltage.**

**Parallel → same voltage, divided current.**
